# SQL Data Analysis Portfolio

Four data analysis projects written in MySQL, covering retail, banking,
e-commerce and insurance. Each project loads a real dataset, cleans it,
and answers business questions using aggregation, CASE segmentation,
window functions and CTEs.

## Projects

| # | Project | Domain | Key techniques |
|---|---------|--------|----------------|
| 1 | [Retail Sales](retail-sales) | Retail | GROUP BY, CASE, window functions |
| 2 | [Customer Churn](customer-churn) | Banking | Churn rate, risk scoring, CTEs |
| 3 | [E-Commerce](ecommerce) | E-commerce | Data cleaning, views, RFM |
| 4 | [Insurance Charges](insurance) | Insurance | Interaction analysis, ranking |

## Skills demonstrated

- Loading and cleaning raw CSV data (including messy, real-world data)
- Aggregation, filtering and grouping (GROUP BY, HAVING)
- CASE-based segmentation and bucketing
- Window functions: RANK, ROW_NUMBER, LAG, SUM/AVG OVER, PARTITION BY
- Common Table Expressions (CTEs) and views
- Translating query results into business recommendations

## Tools

MySQL 8.0, MySQL Workbench. Retail project also connected to Power BI
for dashboarding.
